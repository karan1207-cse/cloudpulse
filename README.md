
# CloudPulse

A serverless cloud reliability and incident response platform.

## Overview

CloudPulse monitors application health, detects service failures,
tracks incidents, and helps developers investigate and verify recovery.

## Planned Features

- Application health checks
- Response-time measurement
- Incident severity and lifecycle management
- Alert deduplication
- Recovery detection
- Incident history and dashboard
- AWS serverless integration
- Automated tests and CI/CD

## Technology Stack

- Python
- AWS Lambda
- Amazon EventBridge
- Amazon CloudWatch
- Amazon SNS
- Amazon DynamoDB
- React and TypeScript
- Terraform
- pytest and GitHub Actions
